置信度分布

标准标签用量

按大类分组,括号里是「被多少个组用到」。用量 0 = 挂着没人用: 要么标准集有冗余,要么提示词没覆盖到这种现象。

非标准标签漏网

库内用过、但不在标准集里的标签 —— 说明别名表没覆盖到。 跑 python scripts/suggest_aliases.py 扫一遍建议,达标的再 --apply。

归并与碎片

每个 (群, 标签) 的理想终态是 1 组(碎片已并回原问题块)。 归并率低说明同标签还散在多个组里;低频标签多说明同义词还在分裂。

进程内指标

这三项是进程内累计(重启归零),只看趋势不看绝对值。 刚部署完看到 0 不代表坏了。
判断阈值不是拍脑袋:未分类率 ≥15% 起警、≥30% 转红 —— 闭集判别的取舍是 「宁可空着也不写脏标签」,所以未分类率高说明闭集缺现象,不是模型不行; gold_groups = 0 时页面顶部会明确说「所有准确率都不作数」—— 没有人工基准,剩下的数字都只是模型自说自话。
